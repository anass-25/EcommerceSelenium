###### \# ***E-Commerce Selenium Automation Testing***

###### 

###### \## Project Overview

###### 

###### This project demonstrates automated functional testing of an e-commerce web application using Selenium WebDriver, Java, TestNG, Maven, and the Page Object Model (POM) design pattern.

###### 

###### \*\*Application under test:\*\* \[TutorialsNinja Demo Store](https://tutorialsninja.com/demo/)

###### 

###### \## Technologies Used

###### 

###### \- Java 21

###### \- Selenium WebDriver

###### \- TestNG

###### \- Maven

###### \- Page Object Model (POM)

###### \- WebDriverManager

###### \- Git and GitHub

###### \- GitHub Actions (Windows CI)

###### 

###### \## Test Automation Features

###### 

###### \- Automated browser interactions

###### \- Functional test execution

###### \- Page Object Model architecture

###### \- Assertions and test validation

###### \- Automated execution using Maven

###### \- Continuous integration with GitHub Actions

###### \- Test execution reports and diagnostic screenshots

###### 

###### \## Prerequisites

###### 

###### \- Java JDK 21

###### \- Maven

###### \- Google Chrome

###### \- Git

###### 

###### \## How to Run the Tests

###### 

###### Clone the repository:

###### 

###### ```bash

###### git clone https://github.com/anass-25/EcommerceSelenium.git

###### ```

###### 

###### Navigate to the project:

###### 

###### ```bash

###### cd EcommerceSelenium

###### ```

###### 

###### Execute the tests:

###### 

###### ```bash

###### mvn clean test

###### ```

###### 

###### \## CI/CD — GitHub Actions

###### 

###### The project uses GitHub Actions to execute automated tests on Windows runners.

###### 

###### Each configured workflow execution can run the Maven test suite and upload available test reports.
